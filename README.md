# 🎮 매일 출석체크 & 카드 가챠 게임 (구글 연동)

구글 로그인 기반의 매일 출석체크, 접속 시간 비례 포인트 획득, 1회 및 10회(11연) 카드 가챠, 등급별 SP 점수 계산 및 1시간 주기 실시간 랭킹 시스템입니다.

---

## 🌟 주요 기능 및 게임 규칙

1. **구글 계정 로그인 & 유저 데이터 처리**:
   - Google Identity Services (GIS) 원클릭 구글 로그인 및 개발용 간편 테스트 로그인 지원.
   - 요청 규격과 100% 일치하는 유저 데이터 JSON 구조 관리:
     ```json
     {
       "uid": "google_auth_uid_12345",
       "nickname": "유저닉네임",
       "main_character": "card_0000",
       "points": 1000,
       "total_sp": 0,
       "last_attendance_date": "2026-09-22",
       "last_sync_timestamp": 1711234567890,
       "is_initial_gift_received": true,
       "created_at": 1711234567890,
       "owned_cards": {
         "card_0000": 1,
         "card_0022": 3
       }
     }
     ```

2. **초기 가입 선물 (5종 중 1장 확정)**:
   - 신규 가입 시 `card_0000`, `card_0022`, `card_0065`, `card_0078`, `card_0156` 중 1장을 무작위로 확정 지급받고 메인 캐릭터로 자동 지정됩니다.
   - 가입 즉시 출석 포인트 1,000P 지급!

3. **출석 체크 & 접속 시간 보상**:
   - **매일 출석체크**: 하루 1회 접속 시 1,000P 지급 (도장 쾅! 연출 및 코인 폭포 연출).
   - **접속 시간 보상**: 접속 유지 1분당 1P 실시간 적립 (실시간 카운트다운 타이머 및 코인 획득 효과).

4. **가챠 소환 시스템 & 화려한 연출**:
   - **가챠 1회**: 100P (카드 1장).
   - **가챠 10회**: 1,000P (**10+1 총 11장** 보너스 획득!).
   - **소환 연출**: 회전하는 마법진, 최고 등급에 반응하는 크리스탈 차징, 카드 공개 이펙트, NEW 뱃지, 중복 획득 시 `DUPLICATE (+SP)` 표시.
   - **절차적 웹 오디오(Web Audio API)** 사운드 효과음 및 캔버스 파티클 시스템 내장.

5. **SP(스코어 포인트) & 랭킹 시스템**:
   - 등급별 SP 점수 (UR: 1000 SP, SSR: 500 SP, SR: 200 SP, R: 80 SP, N: 30 SP).
   - 동일 카드 중복 획득 시 해당 카드의 기본 SP가 추가 누적 (`total_sp = sum(수량 * 기본 SP)`).
   - 1위~10위 SP 랭킹 실시간 보드 (1시간마다 자동 갱신 및 카운트다운 타이머 표시, 내 순위 하단 고정).

6. **카드 도감 & 메인 캐릭터 세팅**:
   - 추후 지속적으로 추가되는 모든 카드에 대한 실시간 동적 수집률 및 등급별 필터링 (전체, UR, SSR, SR, R, N, 보유 카드만).
   - **데이터가 완전히 작성된 카드만 가챠에 출현**하며, 도감에서도 완전한 카드만 집계.
   - 보유한 카드 중 원하는 카드를 즉시 메인 캐릭터로 지정 가능.
   - 배경 이미지 3종 실시간 전환 지원 (`img_bg` 3종).

## 🚀 빠른 실행 방법

### 로컬 서버 실행
별도의 패키지 설치 없이 Node.js가 설치되어 있다면 즉시 실행할 수 있습니다:

```bash
# 프로젝트 폴더로 이동 후
node server.js
```

브라우저에서 `http://localhost:3000` 으로 접속하면 바로 플레이하실 수 있습니다!

## 📊 구글 스프레드시트 연동 방법 (1분 완성)

연동 시트: [구글 스프레드시트 바로가기](https://docs.google.com/spreadsheets/d/1asIP47jypSXf280OkIf5stQZ2TvUQWKZsjDs2vwt_I4/edit?usp=sharing)

1. 위 스프레드시트를 브라우저에서 엽니다.
2. 상단 메뉴에서 **[확장 프로그램]** → **[Apps Script]** 를 클릭합니다.
3. 편집창에 있는 기존 코드를 지우고, 본 프로젝트에 있는 **`GoogleAppsScript.gs`** 파일의 내용을 전체 복사하여 붙여넣습니다.
4. 상단 저장(디스켓 아이콘)을 누릅니다.
5. (시트 탭이 비어있다면) 상단 함수 선택 드롭다운에서 **`initSpreadsheet`**를 선택하고 **[실행]**을 한 번 클릭합니다. (`user`, `cardlist`, `cardrank`, `gacha` 탭과 182종 카드 데이터가 자동 세팅됩니다.)
6. 우측 상단 파란색 **[배포]** 버튼 → **[새 배포]** 를 클릭합니다.
7. 유형 선택(톱니바퀴)에서 **[웹 앱]** 을 선택합니다.
8. 다음 설정을 확인합니다:
   - **설명**: `Toku Gacha API`
   - **다음 사용자 권한으로 실행**: `나(본인 계정)`
   - **액세스 권한이 있는 사용자**: **`모든 사용자(Anyone)`** *(중요: 브라우저 익명 API 호출 허용)*
9. **[배포]** 를 클릭하고 권한 승인을 완료한 뒤, 생성된 **[웹 앱 URL]**을 복사합니다.
10. 게임 화면 우측 상단의 **설정(⚙️)** 아이콘을 클릭하고, 복사한 웹 앱 URL을 붙여넣은 뒤 **[저장]**을 누르면 구글 시트와 실시간 연동이 완료됩니다!
